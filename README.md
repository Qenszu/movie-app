# 🎬 Movie App

A simple movie browsing application built with **React**.

## About

This project was created as a **React practice exercise** — to revisit and reinforce core React concepts such as components, state management, props, and API integration.

## Tech Stack

- **React** — UI library
- **JavaScript**
- **CSS**

## Getting Started

```bash
cd front
npm install
npm start
```
